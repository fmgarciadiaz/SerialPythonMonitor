# Transporte compartido

Herramientas, receptores auxiliares y contratos de las etapas de desarrollo
USB/SPI/UART. Los scripts de diagnóstico pueden importar o incluir estas fuentes;
no es una carpeta de capturas ni se debe archivar como si fuera una versión vieja.

La aplicación Python usa su [receptor propio](../monitor/v15/receiver/README.md).
El relay activo se compila desde la carpeta `relay` de su firmware Arduino.

[Flujo y protocolos](../docs/TRANSPORTE_TECNICO.md).
