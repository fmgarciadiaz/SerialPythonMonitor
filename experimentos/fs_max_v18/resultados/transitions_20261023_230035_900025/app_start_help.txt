Start an Arduino App

Usage:
  arduino-app-cli app start app_path [flags]

Flags:
  -h, --help      help for start
  -v, --verbose   Enable verbose output

Global Flags:
      --format string      Output format (text, json, json-lines) (default "text")
      --log-level string   Set the log level (debug, info, warn, error) (default "error")
