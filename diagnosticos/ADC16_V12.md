# ADC16 V12 · revisión del 5 de octubre de 2026

## Implementación actual

Antigravity integró en V11 P992 PLL2: HSE16 MHz /2 ×25 /4 =50 MHz.
Prescaler ADC DIV1, resolución nativa14 bits, oversampling16 y shift2.
Todos los perfiles ADC usan50 MHz. El límite16 bits por SPI pasa a62,5 kHz;
UART continúa31,25 kHz. No se habilitan100/125 kHz en16 bits.

Para dos canales,16 subconversiones y5 ciclos de adquisición, el tiempo
nominal es32×(5+17)/50=14,08 µs, antes de latencias, frente a16 µs de período.
No equivale a12,16 µs ni a24% de margen. La salida16 bits no certifica ENOB de 16.

## Reloj compartido ADC/DAC

El mux ADCDAC afecta ambos periféricos. La revisión local prepara y verifica
PLL2 antes de arrancar el generador, añade timeout y rechaza una PLL ajena.
Las reconfiguraciones ADC verifican el reloj sin conmutarlo con DAC activo.
La compilación y validación de estas correcciones deben registrarse por
separado; no atribuirles capturas anteriores. HFSEL del DAC se conserva en 01 (0x4000): RM0456, tabla 268, requiere
ese modo cuando HCLK o el kernel DAC supera80 MHz. HCLK permanece160 MHz
aunque el kernel compartido sea50 MHz. [Manual ST](https://www.stmcu.jp/wp/wp-content/uploads/2021/07/RM0456_Rev3.pdf).

El cambio40→50 MHz reduce20% todas las aperturas ADC. Las referencias Bode
anteriores requieren nueva comprobación, incluso si bits/tasa coinciden.
Para evaluar calidad se confirmaA0directoA2/A3 y masa común, comparando
seno de 2/10/20 kHz a16 bits / 50 kHz y16 bits / 62,5 kHz. El DAC de 12 bits no certifica precisión16 bits.

## Comparación analógica del firmware previo a la corrección de arranque

[Cableado directo confirmado y seis capturas](../capturas/adc16_rate/analog_20261005_011139_380174/informe.json):
A0 a A2/A3, seno de 2/10/20 kHz,5 s a16 bits / 50 kHz y16 bits / 62,5 kHz por estímulo.
Continuidad y restauración exacta aprobadas. El campo passed acredita
captura/análisis/restauración, no igualdad de calidad ni precisión absoluta.

| Seno | Cambio de amplitud al subirFs | Residuo RMS A2,50→62,5 kHz |
|---|---|---|
|2 kHz|menos0,001%|1,145→1,138 mV|
|10 kHz|menos0,09%|1,348→1,976 mV|
|20 kHz|aprox+0,22%|1,617→3,383 mV|

A 20 kHz el residuo crece aproximadamente al doble; no afirmar calidad
idéntica en todo el rango. Incluye distorsión del DAC de 12 bits, asentamiento,
ruido y muestreo: no puede atribuirse sólo al ADC con esta prueba.
A2/A3 se adquieren sucesivamente: el desfase observado es aproximadamente 5° a 2 kHz,
25° a 10 kHz y 50° a 20 kHz, compatible con unos 7 µs entre canales; no representa
fase de un circuito si ambas entradas están unidas al mismo estímulo.

Ambos perfiles comparados usan ADC a 50 MHz; este ensayo no compara contra
la implementación anterior de 40 MHz. El aliasing de armónicos del DAC
podría explicar parte del cambio de residuo, pero no fue aislado.
